# ContCrops (كونت كروبس) 🌱

> **سوق زراعي مجاني ١٠٠٪ من الأرض للمصنع للتصدير**  
> يغطي المحاصيل والمنتجات الزراعية: فريش، مجمد، مجفف، تصنيع غذائي، استشارات زراعية، ونقل مبرد.

---

## 🚀 نبذة عن المشروع

**ContCrops** هي منصة ويب حديثة وتفاعلية مصممة لربط جميع أطراف المنظومة الزراعية (المزارعين، التجار، المصانع، شركات التصدير، وشركات الخدمات اللوجستية والنقل المبرد) في بيئة موحدة وسريعة وسهلة الاستخدام.

### ✨ الميزات الرئيسية:
- **سوق العروض والطلبات (Market):** تصفح وفلترة المنتجات الزراعية وتفاصيل الجودة والكميات والأسعار.
- **الخدمات الزراعية (Services):** استشارات زراعية متخصصة، نقل مبرد، ومحطات فرز وتعبئة.
- **بورصة الأسعار اليومية (Prices):** متابعة مؤشرات الأسعار الفورية وتحديثاتها اليومية.
- **نماذج العقود والمستندات (Contracts & Docs):** إنشاء وتخصيص نماذج عقود توريد وتصدير زراعية وتنزيلها بصيغة A4.
- **مجتمع ContCrops (Community):** نقاشات ومشاركات وتجارب حقلية بين المزارعين والمختصين.
- **المراسلات الفورية والإشعارات (Messages & Notifications):** محادثات مباشرة بين أطراف الصفقات مع إشعارات فورية.
- **لوحة تحكم الإدارة (Admin Dashboard):** إدارة المستخدمين والإعلانات والمحتوى والإعدادات.
- **واجهة عربية متكاملة (RTL):** تصميم مريح ومتجاوب بالكامل مع الهواتف الذكية والأجهزة اللوحية والمكتبية.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS v4 (`@tailwindcss/postcss`)
- **Language:** TypeScript
- **Icons:** Lucide React
- **Typography:** Tajawal (Google Fonts)

## 💻 طريقة التشغيل محلياً (Getting Started)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

### 2. تثبيت التبعيات (Install Dependencies)
```bash
npm install
```

### 3. تشغيل خادم التطوير (Run Development Server)
```bash
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
npm run start
```
